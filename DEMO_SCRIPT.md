# 3-minute demo script

## 0:00–0:20 — The problem
State the track problem and why a vector-only search cannot answer it reliably.

## 0:20–0:45 — Ingestion
Run the demo fixture ingestion and show the accepted HydraDB source. Say which structured records are being added.

## 0:45–1:45 — Graph-backed answer
Run the flagship query. Show the answer, source records, and HydraDB graph context/evidence paths. Point out the relationship traversal that makes the answer possible.

## 1:45–2:20 — Hard case
Show the track-specific failure case: a superseded fact, a contradiction, a transitive dependency, or a missing fact. The product must abstain or explain the conflict rather than inventing an answer.

## 2:20–2:50 — Why HydraDB
State exactly what the project would lose without HydraDB: durable context graph, relationship traversal, provenance, and graph-aware retrieval.

## 2:50–3:00 — Close
Show the public repo and the one-command setup.
